# projects/ — 工业化生产目录规范（v14.1）

> 本目录是**全部生产数据的唯一落点**。技能包根目录（scripts/brand/models/docs）是只读引擎，
> 任何一部片子的中间产物与交付物都不得放到包外。参考范式：拍案今评_全视频版_snap_frame/projects。

## 二、命名规则（硬约束）

1. **片名短名**：正片文件夹名=最终交付物文件名前缀，全项目一致；禁止空格/冒号/斜杠；带源文件时保留原名于 batch_list，不要求与文件夹一致。
2. **版本语义**：v2=无旁白对照版；v3=解说带旁白成片；改骨架重出=后缀 _r2/_r3，不覆盖旧版（QC 对照用）。
3. **段落编号**：seg\01..12（两位数），narration 同名段号 01.wav..12.wav，subs 同名 01.ass..12.ass——三处编号必须一一对应，混用=渲染必错。
4. **台账状态**：`待处理 / 进行中 / 完成 / blocked:<一句话原因>`。blocked 必须写原因，不许空挂。

## 三、生产顺序（一条命令链，见 SKILL.md §9 提示词）

结构探测 → 通读（缩略图墙+ASR）→ 定案（plan.json+解说词）→ TTS（tts_bailian）→ 切片粗剪 → snap → 字幕/配音 → concat → 品牌 → 片尾守卫 → QC → 三件套 → 台账回写。
每一步产物落盘后才进下一步；会话断了按本目录产物对账续跑（断点续跑=看哪个文件不存在）。

## 四、开源/二次分发纪律

- source\ 三件套（台词本/新闻源/通读笔记）= 每片出厂必留，作为可复现证据链；新闻源.txt 必须含信息出处。
- 禁止进 projects 的东西：API key、`.env`、私人账号信息、带他人隐私的截图。封面/成片外发前跑 SKILL.md §10.1 脱敏清单。
- 整目录可拷走即用：换机器只改脚本里的相对路径假设（scripts 全部用 __file__ 定位，不依赖盘符）。
